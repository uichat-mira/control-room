# Mira Control Room

Mira organization observability cockpit.

## V0.1

- React + Vite frontend
- Cloudflare Worker API
- Worker Static Assets
- Read-only aggregation by design
- GitHub / Cloudflare / service health adapters will be added incrementally

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

```bash
npm run deploy
```

> Control Room is a projection of existing sources of truth. It must not become a second task ledger or deployment state store.
